# Welcome!

This is a course about Bayesian statistics, targeted at computational biologists

The course takes place over the first three weeks of January 2027 at DTU building 220. If you are taking or want to take that course, congratulations you are in the right place! If not, you may still find something interesting here!

## Learning objectives

The broad aim of the course is for you to learn what Bayesian statistics is, how to practice it and how to improve it.

Here are some more detailed learning objectives:

- Explain common Bayesian statistics terms: space, probability space, prior distribution, measurement model, joint distribution, posterior distribution, Markov Chain Monte Carlo, regression, linear model, generalised linear model
- Determine the space in which some data or parameters live (unconstrained Euclidean space, positive-constrained, simplex, etc.) and apply appropriate transformations
- Describe how gradient-based Markov Chain Monte Carlo works
- Fit a Bayesian statistical model with an embedded dynamical system based on a fed-batch fermentation process.
- Model a measurement apparatus with dropout effects and limited range of detection.
- Diagnose non-convergence, excessive autocorrelation and solver failures from gradient based Markov Chain Monte Carlo outputs
- Evaluate how well a statistical model fits some data
- Choose the right software for a Bayesian statistical modelling problem: high-level formula-based interface, probabilistic programming language or plain JAX.
- Independently plan, implement and write up a project involving Bayesian statistics
- Contribute to making computational Bayesian statistics better
